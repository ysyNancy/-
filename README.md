# 信札 · 每周 AI 回信页

每周日 21:00，信札把这一周的对话写成一封回信。这个仓库是它的回信页：纯静态 HTML / CSS / JS，不依赖任何框架或构建步骤。

> 页面里的人物（小满）、对话、情绪分值都是虚构的示例数据。

## 本地预览

```bash
npm run dev          # 等同于 node scripts/serve.mjs 5173
# 打开 http://localhost:5173
```

没有 Node 时也可以用 `python3 -m http.server 5173`。

## 版式

| 宽度 | 排布 |
| --- | --- |
| < 760px（手机） | 信件 → 周回顾 → 往期，顶栏有分区跳转 |
| 760–1119px | 信件通栏，下方周回顾与往期并排 |
| ≥ 1120px（桌面） | 左往期 · 中信件 · 右周回顾，两侧栏吸顶 |

## 交互

- **信头**：期数、寄出日期、回看区间；「定位链接」把 `#no-38` 写进地址栏并复制整条链接。直接打开 `…/#no-35` 会定位到第 35 封。
- **正文**：九段，三处「原话」按钮可展开当时的原句（带时间戳）。
- **又及**：本周的问题、开头建议、输入框和唯一的实心按钮「现在聊聊」。发送后出现一段模拟对话；草稿和对话保存在本机 `localStorage`。`Ctrl / ⌘ + Enter` 也能发送。
- **周回顾**：七日话题（点一天展开详情，并可「见信第 N 段」跳回正文）、情绪折线（悬停或方向键逐日查看，可切换表格）、三个关键词（点一下在信里圈出出现的位置）。
- **往期**：按月分组，显示未读 / 已回信 / 正在读；点开后信件与周回顾一起切换。

## 文件

```
index.html            页面骨架与 SVG 线稿（花枝、心结、信封标记）
assets/css/style.css  色板、纸纹、版式与组件样式
assets/js/data.js     示例数据（6 封信）
assets/js/app.js      渲染与交互
scripts/serve.mjs     零依赖本地预览服务器
```
